v33 파일 읽기 보완

v32의 Report N/A, 신규 NPI 고객, 공정 형식 비교 기능을 모두 포함합니다.
앱 폴더를 교체하고 Ctrl+F5로 새로고침한 뒤 AI/BI 제목 옆에 v33이 보이는지 확인하세요.
Excel 저장을 마치고 닫은 뒤 파일을 선택하세요.

변경 사항
- arrayBuffer 읽기에 실패하면 FileReader로 한 번 더 시도합니다.
- 읽기에 실패한 결과를 캐시하지 않습니다. 다음 시도 때 실제 파일을 다시 읽습니다.
- 같은 파일을 다시 선택해도 선택 이벤트가 발생합니다.
- 다시 읽기 버튼으로 기존 참조에서 재시도할 수 있습니다. 참조가 만료되었으면 파일을 다시 선택하세요.
- 원본이 실패하고 개정본만 성공한 경우 전체 성공으로 표시하지 않습니다.
- 진단 파일에 버전, 파일 수정 시각, 읽기 방식별 오류를 기록합니다.

검증 범위
현재 A.xlsx(36,689 bytes)와 B.xlsx(104,838 bytes)는 직접 읽기와 비교가 가능하며 변경 17건입니다.
읽기 실패를 주입한 테스트에서 대체 읽기, 실패 캐시 제거, 재시도, 같은 파일 재선택, 상태 표시를 검증했습니다.
이 PC의 실제 Edge 파일 읽기 거부가 해소되는지는 확인하지 못했습니다.
NotReadableError는 브라우저가 파일 바이트를 얻기 전에 발생합니다. 로그만으로 파일 잠금, 참조 만료 또는 환경 제한 중 무엇인지 단정할 수 없습니다.
v33에서도 두 읽기 방식 모두 실패하면 Excel 비교 로직으로 해결할 수 있는 오류가 아닐 수 있습니다. 새 오류 진단 TXT에서 두 방식의 결과를 확인하세요.
