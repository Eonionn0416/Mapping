# REL Schedule v31 적용 안내

v31은 팝업 본문이 26px 체크박스 열에 배치되던 표시 오류를 수정합니다. 본문/마감 정보를 2열로 표시하고 650px 이하에서는 1열로 전환합니다. 기능 및 Excel 로직은 v30과 동일합니다.

## 적용 순서
1. 기존 앱 폴더를 보관한 뒤 ZIP의 wafer_strip_mapping_app을 기존 호스팅에 반영합니다.
2. REL Schedule 페이지를 새로고침합니다. 이전 화면이면 Ctrl+F5로 갱신합니다.
3. 수정된 2643 Excel 3개를 업로드합니다. 기존 데이터 전체 삭제는 필요 없습니다.
4. Uploaded Plan List의 Download Excel로 저장된 일정·발송·승인 정보를 받습니다.

## 고객 양식 유지
- 다운로드는 현재 업로드 파일을 기준으로 처리합니다. 행/열 삽입이나 표 재생성을 하지 않습니다.
- 행 높이, 열 너비, 병합, 인쇄 영역, 셀 서식, 원본 수식과 첨부 개체를 보존합니다.
- 기존 Report 수식의 원본 참조를 우선 사용합니다. Summary는 현재 표의 참조를 따라갑니다.
- BDR은 Interim / Full Qual Rel만 관리합니다. 남아 있는 T1 sanity, Pre-MP SIT, T2 sanity의 Report 셀은 비우고, 다른 내용이 없는 해당 행은 숨깁니다. 아래 상세표의 행 번호를 바꾸지 않기 위한 처리입니다.
- Rel#가 비어 있는 시트는 파일과 Uploaded Plan List에는 보존하지만 Report 발송 관리와 일정 알림에서 제외합니다. Rel# 입력 후 재업로드하면 대상에 포함됩니다.
- 기존 양식에 없는 Report/Summary 표를 자동으로 새로 만들지 않습니다.

## 화면과 알림
- Summary는 알림 대상만으로 고정합니다. 알림 OFF, 완료 및 미입력 일정은 기존 상태 규칙을 따릅니다.
- Pre-alert 체크는 D-2 ~ D-1의 미래 예고만 제어합니다. D-Day와 지연 및 별도 수령/전달 확인은 체크와 무관합니다.
- D-Day·지연 주요 일정 그래프는 알림 대상 Summary를 사용하며 D-Day는 0일, 금색 표식으로 표시합니다.
- 팝업은 오늘 마감 / 기한 경과 / 수령·전달 확인으로 구분합니다. 제목 버튼을 누르면 해당 Plan과 Criteria가 선택되고 정확한 Summary 행으로 이동합니다.
- 지연 항목의 오늘로 변경은 상세표 Delay 및 연결된 날짜 수식을 반영합니다. Excel 다운로드 시 변경이 저장됩니다.
- 발송일 저장 후 다운로드하면 Interim은 주황색, Full은 초록색 탭을 사용합니다.

## BDR 파일 읽기 오류
2643 BDR 원본의 ZIP 구조와 일정 파싱은 정상으로 확인되었습니다. NotReadableError는 Excel 내용을 분석하기 전 브라우저가 운영체제의 파일을 읽지 못했다는 뜻이며 양식 오류와 다릅니다.

파일 내용을 한 번 읽어 파싱·로컬 저장·서버 업로드에 공유합니다. 같은 파일을 다시 선택해 재시도할 수 있습니다. 원본 읽기와 서버 저장 오류는 구분하여 표시합니다.

처음부터 파일 접근이 거부되면 Excel을 닫고, OneDrive 파일을 로컬 폴더에 복사한 뒤 파일 선택으로 새로 지정하세요. 이 경우 브라우저 권한을 앱 코드에서 강제로 우회하지 않습니다. 제공된 updated.xlsx는 로컬 outputs 폴더의 새 파일이므로 해당 파일로 업로드할 수 있습니다.
