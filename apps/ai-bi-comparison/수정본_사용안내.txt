파일 읽기 오류 안내
해당 영문 메시지는 Excel 비교 내용 자체의 오류가 아니라 브라우저가 선택한
파일 내용을 읽을 수 없을 때 발생하는 메시지입니다. 파일 선택 후 파일 변경,
다른 프로그램의 잠금, 접근 권한 제한 등이 원인일 수 있습니다.
첨부 파일은 여기서 정상적으로 읽혔으므로 회사 PC에서의 정확한 원인은 미확정입니다.

수정본은 파일 선택 즉시 내용을 읽어 메모리에 보관하고 비교 때 재사용합니다.
이미 성공적으로 읽은 파일은 그 뒤 디스크 파일이 변경되더라도 선택 당시 내용으로 비교합니다.
최신 내용이 필요하면 파일을 다시 선택해 주세요.
회사 보안 정책이 최초 읽기 자체를 차단하면 이 변경으로 해결되지 않을 수 있습니다.

계속 실패할 경우:
1. Excel 파일을 닫고 회사에서 허용하는 로컬 폴더에 복사합니다.
2. 프로그램에서 초기화 후 복사한 두 파일을 다시 선택합니다.
3. 오류가 계속되면 '오류 진단 TXT 저장'을 눌러 진단 파일을 전달합니다.
   F12는 필요 없습니다. 진단 파일에는 파일명/크기, 브라우저 정보,
   화면 상태, 오류명/메시지가 들어가며 Excel 셀 내용은 포함하지 않습니다.

검증 및 제한
- 첨부 두 파일 비교, 동일 파일 비교 시 차이 0건, 파일 내용 재사용,
  접근 실패 시 파일명과 한국어 안내 표시, 공유 보고서 생성 검증 완료.
- 회사 PC의 실제 보안 정책 및 사용자 브라우저에서는 아직 검증하지 못했습니다.
- 자동 브라우저 표시 검증은 이 환경의 브라우저 실행 문제로 완료하지 못했습니다.
- 값과 수식 문자열 비교이며 서식, 이미지, 도형, 메모, 매크로 비교는 미지원.
- 수식 재계산은 수행하지 않습니다.
- 프로그램의 Excel 읽기 라이브러리는 기존과 같이 인터넷 연결이 필요합니다.
- 실제 사이트에는 배포하지 않았습니다. 기존 사이트 적용 시
  apps/ai-bi-comparison 폴더 전체를 교체하고 새로고침합니다.
- 다른 QA 도구와 원본 ZIP 및 원본 Excel은 변경하지 않았습니다.
