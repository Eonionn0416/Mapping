# AI/BI Comparison 사용 안내

QA Page의 06번 도구로 추가했습니다.

## 실행
1. ZIP을 압축 해제합니다.
2. wafer_strip_mapping_app/index.html을 브라우저에서 열거나 기존 웹사이트에 폴더 내용을 반영합니다.
3. QA Page에서 AI/BI Comparison을 선택합니다.
4. 원본 Excel 하나와 개정 Excel 하나 이상을 선택하고 비교 실행을 누릅니다.
5. 개정 파일, 구분, 검색으로 결과를 확인합니다. 전체 결과 CSV 다운로드로 Excel에서 열 수 있는 보고서를 저장합니다.

Excel 읽기 라이브러리는 기존 도구와 동일하게 CDN에서 로드하므로 처음 화면을 열 때 인터넷 연결이 필요합니다. 업로드한 Excel 내용은 서버에 전송하거나 저장하지 않으며 브라우저에서 비교합니다. 새로고침 후 파일을 다시 선택해야 합니다.

## 비교 방식
- 원본에 포함된 모든 시트와 공정을 매번 읽습니다. 예시 공정 목록을 고정하지 않았습니다.
- `003 [B/G] = BACK GRINDING` 형태의 공정 제목을 인식합니다. 코드와 약어 및 같은 공정의 등장 순서로 개정 파일과 연결합니다.
- 문서 기본 정보, PCB/BOM 정보, 공정 제목, 항목명, 값, 여러 줄 Note를 비교합니다.
- 공정 추가·삭제에 따른 행 이동은 별도 변경으로 표시하지 않습니다. 공통 공정의 순서가 바뀌면 순서 변경으로 표시합니다.
- 추가·변경·삭제는 셀 단위입니다. 항목명과 값이 동시에 추가되면 2건으로 표시할 수 있습니다. 전체 공정/시트 추가·삭제는 상세 내용을 담은 1건으로 표시합니다.
- 원본/개정 셀 주소와 변경 전후 값을 함께 제공합니다. 긴 내용은 전체 내용 보기를 누르면 펼쳐집니다.
- 기본 비교는 공백과 줄바꿈 차이도 감지합니다. 필요하면 공백·줄바꿈 차이 무시를 선택합니다.
- 수식은 수식 문자열로 비교하며 계산 결과의 재계산은 하지 않습니다. 서식, 이미지, 도형, 셀 메모 및 매크로는 비교 대상이 아닙니다.
- 공정 제목 형식이 다른 문서는 기본 정보의 행/셀 비교를 사용하고 안내를 표시합니다. 완전히 다른 표 구조에서도 차이는 표시할 수 있지만 공정별 연결의 정확성은 확인이 필요합니다.
- 공정 코드/약어가 바뀌면 기존 공정 삭제와 새 공정 추가로 표시합니다. 같은 코드가 반복되면 등장 순서로 연결하며 확인 안내를 표시합니다.
- 파일은 각각 50MB까지 지원합니다. 공정/기본 정보 하나의 행 정렬 계산이 4,000,000칸을 넘으면 크기 안내를 표시하고 비교를 중단합니다.
- 시트명이 바뀌면 이전 시트 삭제와 새 시트 추가로 표시합니다.

| SBM 공정 삭제.xlsx | Wheel Vendor 변경, L/G Note 항목명·값 추가, SBM·EVI 공정 삭제 | 5 |
