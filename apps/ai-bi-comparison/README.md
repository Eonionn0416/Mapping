# AI/BI Comparison v2 사용 안내

## 반영 사항
1. 차이가 있는 공정/표를 Before / After로 나란히 보여줍니다. 변경되지 않은 항목도 같이 표시하고 Excel의 병합 셀 배치를 반영합니다. 좁은 화면에서는 위아래로 배치합니다.
2. 변경 셀과 관련 항목명은 노란색, 추가는 초록색, 삭제는 분홍색으로 강조합니다. 공정 전체 삭제 시 After에 '삭제됨', 추가 시 Before에 '원본에 없음'을 표시합니다.
3. 원본과 개정의 AI No 전체 문자열이 일치해야 비교합니다. 앞뒤 공백만 제거하며 괄호 안 개정 표기도 일치해야 합니다. 번호 누락 또는 여러 번호가 존재하는 경우에도 비교를 막고 이유를 표시합니다.
4. CP/BL No의 항목이 없거나 값이 비어 있으면 파일 및 시트별로 'CP/BL No 누락'을 명시합니다. 누락 안내를 표시하되 다른 내용의 비교는 계속합니다.
5. 여러 개정 파일 중 AI No가 다른 파일만 차단하고 일치하는 파일은 비교합니다.

## 실행
ZIP을 압축 해제하고 wafer_strip_mapping_app/index.html → 06 AI/BI Comparison을 선택합니다. 원본 하나와 개정 파일을 선택한 후 비교 실행을 누릅니다. 기존 사이트에 적용할 때는 apps/ai-bi-comparison 폴더 전체를 교체합니다. CSS와 JS 주소에 새 버전 표시를 넣었습니다.

검색·파일 필터·구분 필터는 공정/표 단위로 작동합니다. 구분 필터를 적용해도 해당 공정의 전체 Before / After와 모든 변경 내용을 함께 보여줍니다. 변경 항목 및 셀 위치를 펼치면 상세 위치를 확인할 수 있습니다. 전체 결과 CSV는 비교가 허용된 파일의 상세 변경을 모두 포함합니다.

기본 정보(PCB/BOM 등)는 하나의 표로 묶고, 공정은 원본에서 읽은 코드/약어/등장 순서로 연결합니다. 공정 구성은 고정되어 있지 않습니다. Excel의 실제 색/글꼴은 복제하지 않고 표 배치와 비교 강조색을 사용합니다. 서식·이미지·도형·셀 메모·매크로는 비교 대상이 아닙니다. 수식은 수식 문자열을 비교하며 재계산하지 않습니다. Excel 읽기 라이브러리는 CDN에서 가져오므로 인터넷 연결이 필요하며 파일 내용은 브라우저에서 처리합니다.

## 검증
이전 예시 4개의 회귀 비교, 원본 자기 비교, AI No 불일치·누락 차단, CP/BL No 누락 및 정상 입력을 확인했습니다. 브라우저에서는 SAU Uv Dosage 300mj→200mj 전체 표 표시, 병합 셀, 항목명/값 강조, AI No 불일치 차단 및 다운로드 차단, 정상·불일치 파일 동시 입력, 공정 삭제 표시, 검색 필터를 확인했습니다.

원본 ZIP의 기존 5개 도구는 유지했고 AI/BI Comparison 폴더만 변경했습니다. 실제 사이트 배포는 수행하지 않았습니다.
